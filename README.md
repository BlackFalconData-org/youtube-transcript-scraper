**Compact output** — Emit core fields only (AI-agent / MCP-friendly). Keeps response size small for LLM workflows.

**Result cap** — Stop after N transcripts (up to 5.000). Set to 0 for the full catalog.

## Input parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `startUrls` | array | — | Videos, Shorts, live streams, youtu.be links, embed links or bare 11-character video IDs, plus playlist and channel URLs (every video of the playlist or channel is read, up to Max videos per channel/playlist). One per line. |
| `searchQueries` | array | — | Optional. YouTube search terms; each query returns up to Max videos per search. |
| `languages` | array | `["en"]` | Transcript language codes in order of preference (e.g. en, de, es). |
| `maxItems` | integer | `0` | Upper bound on videos returned in this run across all inputs. 0 = no limit. |
| `maxResults` | integer | `100` | Videos read per search query. |
| `maxVideosPerChannel` | integer | `100` | Videos read from each channel or playlist URL, newest first. 0 = all. |
| `fallbackToAnyLanguage` | boolean | `true` | When none of the preferred languages exists, return the video's default transcript instead of no transcript. |
| `preferAutoGenerated` | boolean | `false` | Pick auto-generated captions over manual ones when both exist in the chosen language. |
| `translateTo` | string | — | Optional language code (e.g. en) to receive a machine translation of the transcript. When a translation is not offered for a video, the original transcript is returned and translationStatus says unavailable. |
| `whisperFallback` | boolean | `false` | When a video has no captions at all, transcribe its spoken audio instead of returning no_captions. Billed as a separate premium event per started minute of audio, charged only for a video that is actually transcribed (see the Pricing tab). Applies to videos up to 30 minutes; longer ones return audio_too_long. The run gets more memory automatically when this is on. Default: off. |
| `outputFormats` | array | `["text","segments"]` | Which transcript formats each record carries: timestamped segments, plain text, SRT and/or WebVTT subtitles. |
| `includeMetadata` | boolean | `true` | Add description, views, likes, publish/upload date, category, keywords and thumbnail to each record. |
| `proxyConfiguration` | object | — | Optional. Leave empty for the built-in default; set your own proxy only if you need a specific one. |
| `descriptionMaxLength` | integer | `0` | Truncate video description to N chars. 0 = no truncation. |
| `compact` | boolean | `false` | Core fields only (for AI-agent/MCP workflows). |
| `excludeEmptyFields` | boolean | `false` | Drop null, empty-string, and empty-array fields from each record before push. Smaller payloads for AI agents and dashboards. |
| `incrementalMode` | boolean | `false` | Compare against previous run state. stateKey is optional — defaults to a value derived from the requested videos and language options so different filter sets never share state. |
| `stateKey` | string | — | Optional. Stable identifier for the tracked search universe. Leave empty to auto-generate from search inputs. |
| `skipReposts` | boolean | `false` | When incremental, skip listings whose content matches an expired listing from a prior run (cross-run duplicate detection). |
| `emitUnchanged` | boolean | `false` | When incremental mode is on, also emit listings whose content has not changed since the last run. |
| `emitExpired` | boolean | `false` | When incremental mode is on, also emit listings that were seen before but are no longer found. |
| `notifyOnlyChanges` | boolean | `false` | When Incremental Mode is on, only send notifications for NEW and UPDATED listings. Has no effect outside incremental mode. |
| `notificationLimit` | integer | `5` | Maximum number of listings included in each notification message (1–20). |
| `telegramToken` | string | — | Telegram bot token (from @BotFather). Required for Telegram notifications. |
| `telegramChatId` | string | — | Telegram chat or channel ID (e.g. "-100123456789"). Required when telegramToken is set. |
| `discordWebhookUrl` | string | — | Discord incoming webhook URL. Server Settings → Integrations → Webhooks → New Webhook. |
| `slackWebhookUrl` | string | — | Slack incoming webhook URL. api.slack.com/messaging/webhooks. |
| `whatsappPhoneNumberId` | string | — | Your WhatsApp Business phone-number ID (numeric, from Meta dashboard). Required when whatsappAccessToken is set. |
| `whatsappAccessToken` | string | — | WhatsApp Cloud API permanent access token (System User token from Meta Business). Recipient must have messaged the business number within the last 24h (service-conversation window — free since Nov 2024). |
| `whatsappTo` | string | — | Recipient phone in E.164 format without + (e.g. "436641234567"). Recipient must have messaged your business number within last 24h. |
| `webhookUrl` | string | — | Receives a JSON POST with {metadata, items} after each run. Universal escape hatch for n8n / Make / Zapier / custom backends. |
| `webhookHeaders` | object | — | Optional JSON object of custom headers (e.g. {"Authorization":"Bearer ..."}). |
| `appConnector` | string | — | Optional. Pick a connected app under Settings → API & Integrations to receive your results (including any contact details). Best-effort across MCP connectors as Apify expands its catalog. |
| `mcpIssueTeam` | string | — | Only when the connected app is an issue tracker: the team (name or ID) the summary issue is created under, if that app requires one. |
